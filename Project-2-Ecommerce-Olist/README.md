# 🛍️ Project 2 – Olist E-Commerce Data Analysis

## 📖 Project Overview

This project analyzes the **Olist Brazilian E-Commerce Public Dataset** to uncover business insights related to sales performance, customer behavior, payment methods, delivery performance, and product categories.

The project follows an end-to-end data analytics workflow, including data wrangling, SQL analysis, exploratory data analysis (EDA), dashboard development, and business insight generation.

---

## 🎯 Objectives

- Clean and prepare the dataset for analysis.
- Perform exploratory data analysis (EDA).
- Analyze customer purchasing behavior.
- Evaluate sales and revenue trends.
- Analyze delivery performance.
- Build interactive dashboards for business insights.

## 🔄 Data Analytics Workflow

### 1. Data Understanding

- Dataset exploration
- Data types inspection
- Missing value identification
- Duplicate checking

### 2. Data Wrangling

- Handling missing values
- Removing duplicate records
- Data type conversion
- Data validation
- Table merging
- Data consistency checking

### 3. Exploratory Data Analysis (EDA)

- Sales trends

- Payment method analysis
